## 3. 组件拓扑

```
浏览器
  │ HTTP :80
  ▼
Nginx  ──  /            → 127.0.0.1:3000（SSE 已关闭 buffering）
  │      └─  /jenkins/   → 未开放（404）
  ▼
Node (systemd: xigu)  ──  SQLite /var/lib/xigu/app.db
```

Jenkins 只监听 `127.0.0.1:8080`，公网无法直连。需要看构建界面时用隧道：

```bash
ssh -L 8080:127.0.0.1:8080 root@8.136.150.236
# 然后本地打开 http://localhost:8080
```

## 4. CI/CD

触发链路：

```
git push origin main
  → Jenkins 任务「智能客服」SCM 轮询（每分钟）
  → sudo /usr/local/bin/xigu-deploy.sh
      git fetch + reset --hard origin/main
      node --check 全量语法校验（失败即回滚）
      systemctl restart xigu
      /api/health 连续 20 次探活（失败即回滚到上一提交并重启）
```

关键文件：

| 文件 | 作用 |
| --- | --- |
| `Jenkinsfile` | 流水线：检出 → 环境/语法校验 → 调部署脚本 → 健康检查 |
| `deploy/xigu-deploy.sh` | 唯一的部署入口，含语法与健康双闸门、自动回滚 |
| `deploy/xigu.service` | systemd 单元 |
| `deploy/nginx-xigu.conf` | 反向代理（含 SSE 配置） |
| `deploy/xigu-watch.*` | 备用触发器：Jenkins 不可用时启用，每分钟比对远端 SHA |

## 5. 日常运维

```bash
systemctl status xigu              # 服务状态
systemctl restart xigu             # 重启应用
journalctl -u xigu -f              # 实时日志
tail -f /var/log/xigu-deploy.log   # 部署日志
curl -s http://127.0.0.1:3000/api/health
```

手动部署（不经过 Jenkins）：

```bash
sudo /usr/local/bin/xigu-deploy.sh
```

回滚：

```bash
cd /opt/xigu/app && git log --oneline -5
sudo git reset --hard <上一个提交> && sudo systemctl restart xigu
```

数据库备份（**不要用 cp**，会丢 WAL 中的数据）：

```bash
sqlite3 /var/lib/xigu/app.db ".backup /var/backups/xigu/app-$(date +%F-%H%M).db"
```

## 6. 安全现状

| 项 | 状态 |
| --- | --- |
| Jenkins 暴露面 | 已收敛到 `127.0.0.1:8080`，公网不可达 |
| 应用管理员 | **仍使用演示口令 `admin/admin123`**，公网可登录，仅适合演示 |
| HTTPS | 未启用（无域名/证书），口令与聊天内容明文传输 |
| 服务器登录 | root 密码登录，未强制密钥 |
| 数据 | 演示数据，无真实客户信息 |
| 安全组 | 仅放行 22 / 80 |

上线为真实业务前必须处理：

1. 修改 `admin` 与 `agent*` 的密码，或删除演示账号；
2. 配置域名 + Let's Encrypt，强制 HTTPS；
3. 关闭 root 密码登录，改为密钥 + 非 root 用户；
4. 按《上线评估报告》关闭 P0-1 ~ P0-10。

## 7. 已知限制

- 单实例：SQLite 单写者 + SSE 在进程内存，无法水平扩展。
- Jenkins 轮询间隔 1 分钟，推送后有最多约 1 分钟延迟；需要秒级可改用 GitHub Webhook（需在仓库侧添加 `http://8.136.150.236/github-webhook/` 并由 Nginx 转发）。
- 部署脚本以 `git reset --hard` 更新代码，服务器上的本地改动会被覆盖，不要直接改线上文件。
